# 🚀 Telegram 2.0 Messenger — Готовый Бэкенд (Supabase)

Этот каталог содержит готовый, протестированный бэкенд для мессенджера Telegram 2.0 на базе Supabase (PostgreSQL + Realtime + Storage + Edge Functions).

---

## ⚡ Быстрый старт за 1 минуту

### Шаг 1: Применить схему базы данных и триггеры
1. Откройте ваш проект в [Supabase Dashboard](https://supabase.com/dashboard).
2. Перейдите в раздел **SQL Editor** в левом меню.
3. Скопируйте содержимое файла [`supabase/schema.sql`](./schema.sql).
4. Нажмите кнопку **Run** (Выполнить).
   - Скрипт полностью **идемпотентный** (безопасен для повторного запуска, не удаляет существующие данные).
   - Создаёт таблицы: `profiles`, `chats`, `chat_members`, `messages`, `message_reactions`, `typing_indicators`, `user_push_tokens`.
   - Включает автоматические триггеры обновления счетчиков непрочитанных сообщений, синхронизации профилей и двойных галочек прочтения (`is_read = true`).
   - Настраивает политики безопасности (RLS) и публикацию Realtime.

### Шаг 2: Настроить хранилище файлов (Storage)
1. В том же **SQL Editor** скопируйте и выполните содержимое [`supabase/storage_setup.sql`](./storage_setup.sql).
2. Либо вручную в разделе **Storage**:
   - Создайте бакет `chat-media` и сделайте его **Public** (публичным).
   - Создайте бакет `avatars` и сделайте его **Public**.

### Шаг 3: Push-уведомления (Опционально)
В папке [`supabase/functions/push-notifier`](./functions/push-notifier) находится готовая Edge Function для отправки Push-уведомлений через Firebase Cloud Messaging (FCM).

## 📦 Что включено в бэкенд

| Функция | Реализация |
|---|---|
| **Регистрация и Вход** | Supabase Auth (Email OTP без пароля, Password) + автоматическое создание профиля |
| **Личные и групповые чаты** | Функция `get_or_create_direct_chat`, оптимизированная выборка участников |
| **Статусы сообщений** | Однократная галочка (доставлено) и двойная галочка (прочитано через `mark_chat_as_read`) |
| **Счетчики непрочитанных** | Триггер `handle_new_message` автоматически инкрементирует `unread_count` собеседникам |
| **Realtime** | WebSocket-подписки на новые сообщения, прочтение, реакцию и статус тайпинга |
| **Тайпинг ("печатает...")** | Таблица `typing_indicators` и функция `set_typing` |
| **Онлайн статус** | Поле `is_online` и `last_seen` в `profiles` + функция `set_user_presence` |
| **Защита данных (RLS)** | Доступ к сообщениям и чатам строго для авторизованных участников диалога |
